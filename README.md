# 🍹 Drinkly - Fresh Drink Website

Landing page interaktif untuk produk minuman segar yang dibuat menggunakan **React** dan **Vite**.

## 🚀 Fitur Utama
- **Interactive Flavor Carousel**: Pergantian varian minuman (Orange Zest, Citrus Mint, Berry Bloom, Blue Calm) dengan penyesuaian tema warna dinamis.
- **Animated Cart & Badges**: Interaksi animasi badge serta efek melayang saat menambahkan produk ke keranjang.
- **Responsive & Modern UI**: Desain UI modern dengan pengalaman pengguna yang halus.

## 🛠️ Cara Menjalankan Project

1. Install dependencies:
   ```bash
   npm install
   ```

2. Jalankan server pengembangan (dev):
   ```bash
   npm run dev
   ```

3. Build untuk produksi:
   ```bash
   npm run build
   ```
